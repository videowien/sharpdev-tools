About this toolkit

A complete browser-based PDF toolkit covering nearly every common PDF operation — merge, split, rotate, delete pages, crop, reorder, insert pages, add page numbers, watermark, fill forms, flatten forms, OCR scanned PDFs, permanently redact sensitive content, sign, compress, and convert PDF to/from JPG, PNG, Markdown, HTML and Word. Every file is processed locally via pdf-lib / pdf.js / Tesseract.js — nothing ever uploads.

Who uses these tools

  • Page-level edits — Merge multiple PDFs, split one into pieces, rotate pages, delete pages, crop margins, reorder pages, insert pages from another PDF.
  • Form workflows — Fill AcroForm fields programmatically, then flatten the form so fields become permanent (not editable).
  • Scan workflows — Run OCR over a scanned PDF to add an invisible searchable text layer — the visual layout stays untouched.
  • Sensitive content — Redact with permanent rasterize-and-burn-in (not just a black rectangle that can be removed by copy-pasting the text underneath).
  • Document polish — Sign with a hand-drawn or typed signature, add page numbers, watermark with text or image, compress to shrink file size.
  • Conversion — PDF ↔ JPG / PNG / Markdown / HTML / Word + Image / Markdown / HTML / Word → PDF.
  • Metadata — Edit PDF metadata (title, author, keywords, subject) without re-saving the document.

Frequently asked questions

Do my PDFs upload to a server?

No — every tool in the PDF category runs entirely in your browser via pdf-lib, pdf.js and Tesseract.js. Even multi-MB scanned documents stay on your device.

Is the redact tool truly permanent?

Yes. Most online redact tools just draw a black rectangle over the text — the original text is still in the PDF and can be extracted with a copy-paste or another tool. This tool rasterizes the page and burns the redaction into pixels, so the original text is removed entirely.

How does the OCR work?

Tesseract.js runs the OCR locally in your browser, then writes the recognised text back into the PDF as an invisible text layer behind the original page image. The PDF looks identical but becomes searchable and selectable.

Can I edit PDF text directly?

Not free-form. PDF was never designed as an editable format — for full editing, convert to Word or HTML first, edit there, then convert back. Form filling and signature placement work in-place.

What's the file-size limit?

There's no hard limit, but performance depends on your device's RAM. Most operations work comfortably with PDFs up to ~100 MB.
