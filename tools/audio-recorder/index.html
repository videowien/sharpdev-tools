Click Record. Your browser will ask for mic permission once.

Tips for a good recording

  • Close to the mic — 15-30 cm away for clarity
  • Quiet room — close windows, turn off fans, mute notifications
  • External mic if possible — USB or Lavalier mics significantly outperform laptop built-in
  • Test with a 5-second clip first — check volume and noise before recording a long piece

What to do with the file

The download is WebM (Chrome/Firefox/Edge) or MP4 (Safari). Both play in nearly every app — VLC, QuickTime, Windows Media Player. To convert to MP3, use a desktop tool like ffmpeg or an online converter.

Privacy

Audio is captured via the browser's MediaRecorder API and held in memory only. Nothing is uploaded.
