Frequently asked questions

What are color harmonies?

They're proven relationships on the color wheel. Complementary uses opposite colors for contrast; analogous uses neighbors for a calm look; triadic and tetradic spread evenly for vibrant schemes; monochromatic varies one hue's lightness.

How do I copy a color?

Click any swatch — its hex code is copied to your clipboard.

Can I start from a random color?

Yes, hit ‘Random base’ to roll a new base color, then tweak the harmony.
