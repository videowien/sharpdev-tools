WiFi QR Code Generator

Create a QR code that connects a phone to your Wi-Fi by scanning, no password typing. Generated entirely in your browser.

Scanning this code connects a phone to your Wi-Fi without typing the password (supported by the iOS and Android cameras). Everything is generated in your browser; the network name and password never leave your device.

Frequently asked questions

How does a WiFi QR code work?

The code stores your network name, security type and password in a standard text format. When a phone camera scans it, the phone offers to join that network automatically, so guests connect without typing anything.

Is it safe to share?

Anyone who scans the code gets your Wi-Fi password, so treat the image like the password itself. It is generated locally in your browser and never uploaded, but share the printed code only with people you trust on your network.

Which phones support it?

Recent iPhones (iOS 11 and later) and most Android phones read WiFi QR codes straight from the camera app. Older phones may need a dedicated QR scanner app.
