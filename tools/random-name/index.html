Frequently asked questions

What can I use random names for?

Seeding databases and tests, mock user lists, design mock-ups, character ideas, sign-up form placeholders, and anywhere you need realistic but fake names.

Are these real people?

No. Names are assembled randomly from common first and last names, so any match to a real person is coincidental.

Can I get only male or only female names?

Yes — use the gender selector. ‘Any’ mixes both.
