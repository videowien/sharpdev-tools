Common aspect ratios at a glance

  • 16:9 — YouTube horizontal, TV, monitors, presentation slides (1920×1080, 3840×2160)
  • 9:16 — Instagram Reels, TikTok, YouTube Shorts, Snapchat (1080×1920)
  • 4:5 — Instagram feed portrait, Facebook portrait (1080×1350)
  • 1:1 — Instagram feed square, profile pictures, podcast cover art (1080×1080, 3000×3000)
  • 3:2 — DSLR & mirrorless cameras (most Canon, Nikon, Sony) (6000×4000)
  • 4:3 — Classic TV, older monitors, iPad (1600×1200)
  • 21:9 — Cinematic ultra-wide, anamorphic film, ultrawide monitors (2560×1080, 3440×1440)

How the aspect ratio converter works

An aspect ratio is just width divided by height. A 16:9 image is 16 units wide for every 9 units tall — at any size. This converter lets you pin two values and solve for the third: type a width to find the matching height for a given ratio, or type both dimensions to discover what ratio you have. The live preview on the right shows you the shape at scale.

When to use this aspect ratio editor

  • Before exporting from Premiere / DaVinci / Final Cut — nail the target resolution for the platform you're publishing on.
  • When cropping in Photoshop or Lightroom — figure out the exact dimensions to crop to for Instagram, print or web.
  • When resizing assets in Figma or Sketch — keep proportions while changing one dimension.
  • When building responsive layouts — calculate aspect-ratio: 16 / 9 CSS values for video containers.
