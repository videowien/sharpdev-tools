Speech-to-Text

Click record, speak — watch the text appear. Chrome / Edge / Chromium browsers.

⚠ Your browser doesn't support speech recognition. Try Chrome, Edge, Brave, or any Chromium-based browser.

Tips for accuracy

  • Quiet environment — background noise drops accuracy fast
  • Speak naturally, not too slow — recognition models train on natural speech
  • Headset / external mic beats laptop built-in mic by a lot
  • Punctuation by voice — say "comma", "period", "question mark", "new line"
  • Match language exactly — Spanish (Spain) vs (Mexico) differ in vocabulary

Privacy note

The Web Speech API in Chromium browsers sends audio to Google's cloud servers for recognition. The audio isn't stored, but it does leave the browser. For fully-offline transcription, you'd need a native app with Whisper or similar.
