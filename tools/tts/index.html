Text-to-Speech

Hear typed text spoken aloud. Uses your OS voices via Web Speech API.

Voice quality varies by OS

OSQuality
macOS / iOSExcellent (Siri voices)
Windows 10/11Good (David, Zira, neural voices)
AndroidGood (Google TTS)
LinuxRobotic by default (eSpeak); installs improve it

Tips

  • Add commas + periods — they give natural pauses; pure paragraphs sound robotic
  • Slow down with rate 0.8 for unfamiliar words; speed up to 1.5 for fast reading practice
  • Match voice to language — using an English voice on German text sounds awful (and vice versa)

Privacy

The Web Speech API runs locally on your device. No audio is uploaded.
