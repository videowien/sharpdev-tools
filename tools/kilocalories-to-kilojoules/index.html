Frequently asked questions

How do I convert kilocalories to kilojoules?

Multiply the kilocalorie value by 4.184. So 1 kilocalorie = 4.184 kJ, and the calculator above does it instantly for any number.

How many kilojoules are in a kilocalorie?

There are 4.184 kilojoules in one kilocalorie. The reference table shows the conversion for common values.
