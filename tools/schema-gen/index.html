Best practice

  • Be accurate — never schema something that's not visible on the page. Google penalises "structured data spam"
  • One JSON-LD per page is fine, but you can have multiple. Combine in one array for cleanliness
  • Test in Rich Results Test after deploying — visible doesn't mean valid
  • FAQ schema only works for genuinely Q&A content — Google deprecated it for general use in 2023
