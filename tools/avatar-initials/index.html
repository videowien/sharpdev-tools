Where to use initials avatars

  • Default user avatars — for accounts without an uploaded photo (Gmail, Slack, Notion all do this)
  • Team directory — every team member gets a colored letter circle as a fallback
  • Comment systems — assign a deterministic color per commenter so threads have visual variety
  • Email signatures — small initial circle next to your name reads more polished than a Gravatar placeholder

Color tips

  • Saturated, mid-light backgrounds work best — white text on too-light a background is unreadable
  • One color per user, deterministic — derive from name hash so the same person always gets the same circle
  • Avoid grey for branded contexts — it reads as "missing image" not "stylish avatar"

Privacy
