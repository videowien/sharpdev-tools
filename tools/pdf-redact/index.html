How this is different from "drawing a black rectangle"

Most cheap redaction tools simply draw a vector rectangle over the text. The text underneath stays in the file — it's just hidden visually. Anyone with a PDF editor (or even copy-paste) can recover it.

This tool rasterizes each redacted page: renders to image, draws the black bars at pixel level, and replaces the page with an image-only version. The text is genuinely destroyed.

Trade-off: redacted pages lose searchability

Because affected pages become images, they're no longer searchable or selectable in the output PDF. Non-redacted pages are unchanged.

For sensitive documents

For truly sensitive material (court filings, classified docs, GDPR-relevant data), use a professional redaction tool with audit trail (Adobe Acrobat Pro). This tool is for routine privacy (sharing a screenshot of a PDF with bystander info redacted).

Privacy

Everything runs in your browser. The PDF is never uploaded.
