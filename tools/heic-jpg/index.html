Why HEIC exists

HEIC (High Efficiency Image Container) is Apple's default photo format since iOS 11. It uses HEVC compression — ~50% smaller than JPG at the same quality. Great for storage on the iPhone, terrible for sharing: Windows can't open it natively, most web tools don't accept it, and email previews are blank.

JPG vs PNG for output

  • JPG — smaller file size, good for photos, lossy. Most universal format.
  • PNG — larger file size, lossless, supports transparency. Use when sharing for further editing.

iPhone setting to avoid this

To stop iPhone from saving as HEIC: Settings → Camera → Formats → "Most Compatible". New photos will save as JPG. Existing HEIC photos still need conversion.
