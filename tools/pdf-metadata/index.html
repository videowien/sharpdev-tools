Privacy: strip before sharing

If you've ever opened a PDF and seen your colleague's full name + their internal app version in the file metadata — that's because most authoring apps embed it by default. Click Strip all metadata to clear every field before sharing externally.

SEO for PDFs

Google indexes PDFs and shows the Title metadata as the search result link (falling back to filename if missing). Set a clean, keyword-rich title — same SEO rules as web pages.
