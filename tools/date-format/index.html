Why ISO 8601 is the right default

YYYY-MM-DD sorts correctly as a string (newer dates sort larger), avoids the US/EU ambiguity (is 03/04 March 4th or April 3rd?), and is the international standard. Adopted by SQL, JSON Schema, Git, and every modern logging system. If you're choosing a format for storage or APIs, pick ISO 8601.
