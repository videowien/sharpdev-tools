How to use

  1. Drop or pick an image.
  2. Hover over the image — color values follow your cursor.
  3. Click to add to your palette (right side).
  4. Click any palette swatch to copy its HEX value.

Common use cases

  • Extracting brand colors from a logo
  • Matching CSS colors to a screenshot or mockup
  • Building a color palette from a photo for a design
  • Finding the exact accent color a competitor uses
