What makes a good username?

  • Short + memorable — under 15 characters is the sweet spot. Twitter limits handles to 15, Instagram to 30.
  • Read it out loud — if it's awkward to say, it's awkward to share.
  • No leetspeak unless on purpose — n00bm4ster reads as 2008.
  • Consider all platforms — once you pick a handle, check it on every service you might use (Namechk-style).

Theme cheatsheet

  • Professional — clean, neutral adjectives + occupations. Good for LinkedIn / freelance.
  • Gamer — punchy + slightly aggressive vocabulary. For Twitch / esports / Discord.
  • Cute / aesthetic — soft, food-and-nature-inspired words. Tumblr / aesthetic Instagram.
  • Dev / tech — programming and infra terms. For GitHub / Mastodon / dev Twitter.
  • Dark / edgy — gothic / cyberpunk vocabulary. For metal Twitter / synthwave accounts.
