Markdown TOC Generator

Paste your Markdown — get a copy-paste table of contents with GitHub-style anchor links.

















GitHub anchor rules


    

  • Headings are slugified to lowercase
    • 

  • Spaces become hyphens
    • 

  • Apostrophes, dots, and other punctuation are removed
    • 

  • Duplicate slugs get -1, -2, … suffixes
    • 

  • Emojis are stripped
    • 




Common patterns


    

  • README files — min 2 (skip the H1 = title), max 3 — keeps the TOC short
    • 

  • Long technical docs — min 2, max 4 — captures detail
    • 

  • Quick reference — min 2, max 2 — only top-level sections
