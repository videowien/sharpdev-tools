Frequently asked questions

How do I convert days to seconds?

Multiply the day value by 86400. So 1 day = 86400 s, and the calculator above does it instantly for any number.

How many seconds are in a day?

There are 86400 seconds in one day. The reference table shows the conversion for common values.
