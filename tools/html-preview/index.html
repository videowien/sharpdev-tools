Frequently asked questions

What is the HTML preview for?

Paste any HTML and see it rendered immediately, without creating a file or opening an editor. Handy for checking a snippet, email markup, or how some pasted HTML actually looks.

Why are scripts disabled?

The preview runs in a sandboxed iframe without script execution, so pasted HTML cannot run JavaScript against your browser. Layout, text and CSS render fully; only scripts are blocked.

Is my HTML uploaded?

No, it renders locally via the iframe srcdoc attribute. Nothing leaves your browser.
