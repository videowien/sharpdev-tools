Common use cases

  • Before/after comparisons — renovation, design iterations (500-1000ms delay)
  • Tutorial animations — show a sequence of UI steps (200-300ms)
  • Product showcases — multiple angles of a product (300-500ms)
  • Memes / reactions — fast-cut funny sequences (50-100ms)

Tips for smaller files

  • Reduce dimensions — file size scales with width × height
  • Fewer frames — 5 well-chosen frames beat 20 incremental ones
  • Lower quality — "Faster" or "Fastest" trades visual quality for smaller files

Privacy

Images and the resulting GIF stay in your browser. Encoding via gif.js (Web Worker).
