How position works

  • 0 — insert at the very start (insert PDF becomes the new first page(s))
  • N — insert after page N (so insert appears between page N and page N+1 of the base)
  • Total pages of base — insert at the very end (same as Merge)

Page-range syntax

Same as PDF Split: 1-3 for a range, 5,7,9 for specific pages, 1-3,5,8-10 for combinations. Blank = all pages.

Privacy

Both PDFs are processed in your browser via pdf-lib. Nothing is uploaded.
