Common use cases

  • Classroom raffles — pick a student to answer / present
  • Giveaway draws — random winner from a list of entries
  • Team standups — who goes first today?
  • Where to eat? — list options, let the wheel decide
  • Yes/No decisions — for a binary one, the Decision Maker is faster

How fairness works

The result is picked with crypto.getRandomValues() — the same source browsers use for cryptography. The wheel animation just rotates to land on the pre-decided slice, with enough rotations to feel suspenseful. The outcome is fair, not the animation.
