How to use your sitemap

  1. Upload sitemap.xml to your site root (e.g. https://example.com/sitemap.xml)
  2. Reference it in robots.txt: Sitemap: https://example.com/sitemap.xml
  3. Submit in Google Search Console → Sitemaps
  4. Submit in Bing Webmaster Tools too

Priority + changefreq are advisory

Google has confirmed it largely ignores the priority and changefreq fields. They're hints, not commands. Focus on lastmod — that one is still used to detect changed pages.
