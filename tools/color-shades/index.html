Color Tints & Shades

Tailwind-style 50-900 scale from any base color. Copy as HEX, RGB, HSL or CSS variables.

How tints and shades are generated

The base color sits at 500. Tints (50-400) are generated by interpolating toward white in HSL space (raising lightness). Shades (600-900) toward black (lowering lightness). The exact lightness steps are based on Tailwind's defaults.

Where to use each step
