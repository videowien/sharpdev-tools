HTML to PDF Converter

Paste HTML, see a live preview, download a clean PDF. Free, instant, runs in your browser.

How does HTML to PDF conversion work?

The HTML you paste renders into a sandboxed iframe (so it can't run scripts or talk to any network). When you click Download PDF, html2canvas rasterizes the rendered page and jsPDF assembles the result into a paginated PDF. Everything runs in your browser — your HTML content never leaves your device.

What's supported?

  • Standard HTML tags — headings, paragraphs, lists, tables, blockquotes, code, links
  • Inline CSS — both <style> blocks and style="…" attributes
  • Embedded data-URL images — <img src="data:image/…;base64,…"> works perfectly
  • External images — load only if the source allows cross-origin access (most won't)

What's not supported (browser limitations)

  • External stylesheets (<link rel="stylesheet">) — paste the CSS into inline <style> tags instead
  • External fonts and scripts — also blocked by the sandbox
  • Form interactions — the PDF is a snapshot, not interactive

Common use cases

  • Exporting an HTML report from a generator script as a clean PDF
  • Saving an email-newsletter design as PDF for archiving
  • Turning a styled HTML invoice template into a downloadable PDF
  • Converting a hand-coded landing page to PDF for client review
