The hidden YouTube title cutoffs

YouTube technically allows 100 characters. But what users actually see depends on where the title appears:

SurfaceVisible chars
Desktop search results~70
Mobile search results~55
Suggested videos sidebar~45
End screens / Mobile feed~40
Notifications~30

Best practice — front-load the hook

  • First 40 chars carry the click — the rest is for SEO long-tail keywords
  • Lead with the value proposition or pattern interrupt — "I tried X for 30 days" beats "What I learned trying X"
  • Use brackets for tone — [Free], (no API needed), {2026 update} all signal type-of-content
  • Avoid all-caps — YouTube downranks it as clickbait

Privacy

Counter and preview run entirely in your browser. Nothing is uploaded.
