Frequently asked questions

What counts as a palindrome here?

A palindrome reads the same forwards and backwards. The checker ignores capitalization, spaces and punctuation, so 'A man, a plan, a canal: Panama' counts as a palindrome.

Does it work for numbers?

Yes. Numbers like 12321 are checked the same way, useful for spotting palindromic dates or numeric palindromes.

Does it run in my browser?

Yes, instantly and entirely client-side.
