YouTube URL Cleaner

Strip ?si=, ?feature=, ?pp= and other tracking parameters. Keeps legit params (v, t, list, start).

Removed:

What gets stripped

  • ?si= — share-source identifier (tells YT where shares came from)
  • ?feature= — referral feature attribution
  • ?pp= — playback parameters used for tracking
  • ?app= — app-source identifier
  • &ab_channel= — sometimes added by YT for channel attribution
  • &utm_source=, &utm_medium=, etc. — campaign tracking from third parties
  • Any other param starting with ref, src, utm or tracking

What stays

  • ?v= — the video ID (obviously)
  • ?t= or &t= — start-at-timestamp deep link (e.g. ?t=42)
  • ?start= — embed-style timestamp
  • ?list= — playlist ID
  • ?index= — position in playlist

Common use cases

  • Sharing a cleaner link in a tweet/post/email without the share-source telemetry attached
  • Building documentation that references YouTube videos — strip clutter for readability
  • Avoiding broken links when YT eventually changes/deprecates internal tracking schemes
