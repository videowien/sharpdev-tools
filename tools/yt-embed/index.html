YouTube Embed Code Generator

Paste a YouTube URL, pick options, copy the <iframe> snippet. Works with youtube.com and youtu.be.

Available iframe parameters

  • autoplay=1 — starts playing immediately (requires mute=1 in most browsers)
  • mute=1 — starts muted (required for autoplay to actually work)
  • loop=1 — restarts at the end (also requires playlist=VIDEO_ID for it to work)
  • controls=0 — hide the player controls (no play/pause/seek/volume)
  • modestbranding=1 — minimize the YouTube logo
  • rel=0 — don't show related videos at the end (since 2018, "rel=0" means "from the same channel" — true zero-related isn't possible)
  • start=N — start at second N
  • Domain: youtube-nocookie.com sets no cookies until play — GDPR-safer

Responsive (16:9) embed code

When "Responsive" is checked, the iframe uses 100% width and the parent container uses an aspect-ratio CSS trick. Drop the generated CSS + HTML into your page and the video will scale with the container.
