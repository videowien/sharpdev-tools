Frequently asked questions

What is an nth root?

The nth root of a number is the value that, multiplied by itself n times, gives that number. The 2nd root is the square root, the 3rd root is the cube root, and so on. Set the root field to choose n.

Can I take the root of a negative number?

An odd root of a negative number is a real negative value, for example the cube root of -8 is -2. An even root of a negative number is not a real number, so the tool says 'not real'.

What is the check value for?

It raises the result back to the nth power so you can confirm it returns your original number. Small rounding differences can appear because roots are often irrational.
