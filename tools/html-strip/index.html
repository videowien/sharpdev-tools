HTML Strip — Remove HTML Tags Online

Paste HTML, get clean plain text. Strip all tags, decode entities, keep paragraph breaks. DOMParser-based — handles real-world HTML.

—

Common use cases

  • Extract article text — paste an article's HTML, get clean reading-ready text
  • Email body cleanup — strip rich-text formatting before reposting
  • Word count from HTML — get the actual visible word count, not the markup-bloated number
  • SEO content audit — see what crawlers actually read on a page
  • Email preview text — what an email client shows before HTML rendering

What's stripped

  • <script>, <style> and HTML comments — removed entirely
  • <img>, <svg> — removed (no alt-text fallback by default)
  • All other tags — removed but their text content is kept
  • Entities — decoded (&mdash; → —, &nbsp; → space)

Privacy

Parsing happens in your browser via DOMParser. Nothing is uploaded.
