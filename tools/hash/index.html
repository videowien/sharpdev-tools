About these hashes

MD5 and SHA-1 are broken for security but still useful as checksums. SHA-256 and SHA-512 remain secure. All hashing happens in your browser using the Web Crypto API (MD5 uses an inline implementation since it's not in the standard). Nothing is uploaded anywhere.
