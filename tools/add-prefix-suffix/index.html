Add Prefix & Suffix to Each Line

Wrap every line of your text with a prefix and a suffix. Handy for quoting lists, adding bullets, commas, tags or SQL values.

Frequently asked questions

What can I use this for?

Anything that needs the same text added to every line: wrapping a list of values in quotes for SQL or JSON, adding HTML tags around each line, prepending bullets or dashes, or appending a trailing comma to each item.

Does it handle empty lines?

By default empty lines are left untouched so you do not get stray prefixes and suffixes on blank rows. Untick the option to wrap every line including empty ones.

Is the text processed privately?

Yes. Everything runs in your browser and nothing is uploaded.
