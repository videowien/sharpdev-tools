Frequently asked questions

What is this for?

Would You Rather is a classic conversation game: each round poses two options and everyone picks one and defends it. Great for parties, classrooms, road trips and team icebreakers.

How many questions are there?

A built-in set of dilemmas spanning silly, deep and everyday choices, drawn at random so you rarely repeat in a session.

Does it work offline?

Once the page is loaded, yes, the questions are bundled in, no network needed.
