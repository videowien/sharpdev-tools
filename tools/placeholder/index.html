Common use cases

  • Frontend prototyping — fill <img> tags before assets arrive
  • Design mockups — drop into Figma / Sketch / Affinity as a fast stand-in
  • Email templates — bake size hints into test sends so the recipient knows what's missing
  • Print mockups — quick squares for InDesign / Affinity Publisher layouts

Tip: bake the size into the filename

If you generate many placeholders, the auto-generated filename includes {width}x{height}. Drop them into a folder and you can scan dimensions at a glance.
