Every case format, explained

UPPERCASE
All letters capitalized. Use for shouty emphasis or constants in some languages. "HELLO WORLD"
lowercase
All letters in lower case. Use for URLs, file paths, IDs. "hello world"
Title Case
First letter of each word capitalized. Standard for headlines and titles. "Hello World"
Sentence case
Only the first letter and proper nouns capitalized. Use for paragraph text. "Hello world"
camelCase
First word lowercase, every subsequent word capitalized, no separators. Standard for JavaScript and Java variables. "helloWorld"
PascalCase
Like camelCase but the first letter is also capitalized. Standard for class names. "HelloWorld"
snake_case
Lowercase words separated by underscores. Standard for Python variables and SQL. "hello_world"
kebab-case
Lowercase words separated by hyphens. Standard for CSS classes and URL slugs. "hello-world"
dot.case
Lowercase words separated by dots. Common in config keys and namespaces. "hello.world"
CONSTANT_CASE
UPPERCASE words separated by underscores. Standard for environment variables and named constants. "HELLO_WORLD"
tOGGLE cASE
Inverts the case of every letter. Used for mockery, debugging or just for fun. "hELLO wORLD"
Capitalize Words
Same as Title Case but preserves words that were already in mixed case (useful for proper nouns).
