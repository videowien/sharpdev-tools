Use cases

  • Design from a moodboard — extract palette from a reference photo
  • Brand colors from a logo — get exact hex codes
  • Theme color from a hero image — pick a fitting accent color
  • Album / book cover palettes — vibe-match a design to existing visuals

How median-cut works

The algorithm bins all the image's pixels into a 3D RGB cube. It repeatedly splits the most-populous bucket along its longest axis until you have N buckets, then averages the colors in each. It's fast, deterministic, and gives well-distributed palettes.
