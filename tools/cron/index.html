    Cron syntax

    ┌── minute (0-59)
│ ┌── hour (0-23)
│ │ ┌── day of month (1-31)
│ │ │ ┌── month (1-12 or JAN-DEC)
│ │ │ │ ┌── day of week (0-6 or SUN-SAT, 0=Sunday)
│ │ │ │ │
* * * * *
    • * — any value
    • */N — every N steps (e.g. */15 for every 15)
    • N-M — range from N to M
    • N,M,O — list of specific values
    • MON, JAN — English day/month names
