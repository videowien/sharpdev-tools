What makes this different from other notepads

  • Privacy first — your notes never leave your browser. No account, no upload, no sync
  • Autosaves on every keystroke — no save button, no data loss
  • Survives reloads — close the tab, come back, your notes are still there
  • Per-device storage — opening on a different device starts fresh (privacy feature)

When this is useful

  • Quick drafts — paste something to clean up, write a tweet, draft a reply
  • Side note while researching — keep a tab open with thoughts as you browse
  • Meeting notes — type along, download as TXT when done
  • Markdown drafts — write your README / blog post here, export as .md

Backup tips

Since notes live only in your browser, periodically download as TXT or MD if the content matters. Clearing browser data (or going incognito) will delete the notes.

Privacy

Notes are stored in your browser's localStorage. They are not uploaded, never visible to us, and are tied to this exact device + browser combination.
