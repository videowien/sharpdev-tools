PDF Form Fill

Open any AcroForm PDF, fill every field, save the completed file.

Drop a PDF form here or click to browse

PDF must contain AcroForm fields

Field types supported

  • Text fields — type any value
  • Checkboxes — check / uncheck
  • Dropdowns — pick from the form's option list
  • Radio buttons — pick one option from a group
  • Option lists — multi-select where allowed

If the PDF has no fillable fields

Some PDFs look fillable but actually have no AcroForm fields — the "fields" are just visual boxes. In that case, use the PDF Sign tool to drop signature / text images at any position, or use a desktop tool like LibreOffice Draw to add proper fields.

Privacy

Everything stays in your browser via pdf-lib.
