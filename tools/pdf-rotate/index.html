How does PDF rotation work?

This tool reads your PDF with pdf.js to render preview thumbnails, then uses pdf-lib to set the rotation metadata on each page when you save. The pages themselves aren't re-rendered or re-saved as images — only the rotation flag changes, so quality and file size stay identical.

Click thumbnails to rotate individual pages

Each click on a thumbnail rotates that single page 90° clockwise. Click multiple times to reach 180° or 270°. The bulk "Apply to all" buttons override every page at once with the chosen rotation.

Common use cases

  • Fixing scanned pages that came out sideways
  • Correcting phone-photo PDFs where some pages are upside-down
  • Rotating a landscape title page in an otherwise portrait document
  • Flipping every page 180° on a PDF that was scanned upside-down
