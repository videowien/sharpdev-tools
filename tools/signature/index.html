How to install






Gmail


Click "Copy as rich text", then go to Settings → See all settings → General → Signature. Paste into the signature box.






Outlook (web / desktop)


File → Options → Mail → Signatures. Create a new signature and paste as rich text. For the web: Settings → Mail → Compose and reply.






Apple Mail


Mail → Settings → Signatures. Create a new signature, then paste as rich text. Uncheck "Always match my default message font".
