About this toolkit

A complete browser-based image toolkit — compress, resize, convert (HEIC ↔ JPG, PNG ↔ WebP), crop, rotate, OCR scanned images, extract dominant colors, run EXIF analysis, generate favicons and even build animated GIFs. Everything runs locally; your files never upload.

Who uses these tools

  • Web-image optimization — Compress and resize for site performance, convert HEIC → JPG for older browsers, generate WebP for modern ones.
  • Image conversion — Format converter handles PNG, JPG, WebP, GIF, BMP, AVIF, HEIC. Image-to-Base64 produces data URLs for inline embedding.
  • Color & design extraction — Dominant-color palette extraction from any image, single-pixel color picker.
  • Document & photo OCR — Tesseract.js-powered OCR turns scanned images into searchable text — no upload to a cloud OCR API.
  • Asset generation — Favicon generator (multiple sizes), animated GIF maker, photo collage builder.
  • Metadata & cleanup — EXIF viewer to inspect camera + GPS metadata, pixelate / blur for redacting sensitive areas.

Frequently asked questions

Do my images upload to a server?

No. Every image tool in this category runs entirely in your browser. Even OCR uses Tesseract.js (browser-based) instead of a cloud OCR API. Your images never leave your device.

Which image formats are supported?

PNG, JPG / JPEG, WebP, GIF, BMP, SVG, AVIF and HEIC. The Format Converter handles conversion between any pair.

How does the OCR tool work without an API?

It uses Tesseract.js — a port of the open-source Tesseract OCR engine to JavaScript / WebAssembly. Slower than a cloud API but completely private.

Can I batch-process multiple images?

Many tools (compressor, converter, resize) support multi-file drag-and-drop. Each file is processed in your browser one after another.
