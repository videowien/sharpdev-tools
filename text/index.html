About this toolkit

Whether you're a writer fixing word counts, a developer normalising case in code, or an SEO doing keyword density analysis, this collection of free online text tools covers the full lifecycle of writing and editing text — all running in your browser with nothing uploaded.

Who uses these tools

  • Writers & editors — Count words, normalize case to Title or Sentence case, generate Lorem Ipsum placeholders, sort lines, find & replace across long docs.
  • Developers — Convert between camelCase / snake_case / kebab-case, diff two strings, strip whitespace, decode HTML entities, slugify text for URLs.
  • Content marketers — Run keyword density analysis on draft posts, check reading level, count characters for tight ad copy, preview Markdown in real time.
  • Students & researchers — Word + character count for essays, diff two versions of a draft, extract clean text from copied HTML.
