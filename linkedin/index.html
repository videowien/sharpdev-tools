Frequently asked questions

What's the character limit for a LinkedIn post?

3000 characters for personal feed posts, 1250 for comments, 700 for InMail. The Post Counter shows you all the limits in one view.

What's the right size for a LinkedIn banner?

1584×396 pixels. The Banner Sizer template marks the area covered by your profile picture so you can position text + branding safely.

Do these LinkedIn tools work without logging in?

Yes — everything runs in your browser. No LinkedIn login, no API key, no data sent anywhere.

Can I publish straight from these tools to LinkedIn?

No — that would require a LinkedIn login which we won't ask you for. Copy the text or download the asset and paste / upload it yourself on LinkedIn.
